# codingRules

**Code Style:**
   - Use **Allman** (BSD) style for all code blocks
   - Use **lowerCamelCase** for function and variable names
   - Use **Object Calisthenics** (zie: https://williamdurand.fr/2013/06/03/object-calisthenics/)
   - Use <Serial>.printf() and snprintf()
   - Use std::string and not String
   - Prefix all comments with `//--`
   - Place comments above the code block they describe (if more then 10 lines or so)
   - Indent two (2) spaces
   - Never remove empty lines or skip code sections

Use the Code Style for .cpp, .c, .h,  .js, .php, .css files
